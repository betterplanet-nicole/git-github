# Talk to My Energy Utility Landing App

A production-style starter implementation of the `talktomyenergy.com/utility` concept with:

- Front-end marketing page and lead form.
- Back-end API endpoints for lead intake.
- AWS solution recommendation endpoint for architecture guidance.

## Run locally

```bash
npm start
```

Open `http://localhost:3000`.

## API endpoints

- `GET /api/aws-solution`
- `POST /api/leads`
- `GET /api/leads`

## Test

```bash
npm test
```
